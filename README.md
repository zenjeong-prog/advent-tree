# 나의 성탄 트리 꾸미기 — 화면 미리보기

cpbc플러스 대림 이벤트의 화면 흐름 시안입니다. 서버 없이 브라우저에서만 동작하며, 입력한 내용은 새로고침하면 처음 상태로 돌아갑니다.

## GitHub Pages로 올리기
1. 이 폴더의 `index.html`, `assets/` 를 저장소 최상단(또는 `docs/`)에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment** 에서 Source를 `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)`(또는 `/docs`)로 저장합니다.
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

## 구성
- `index.html` — 화면 전체(HTML·CSS·JS 한 파일)
- `assets/` — 트리, 대림초(불꽃 분리), 오너먼트 29종 + 흰 초(임시), 편지지 4종, 배경 11종 (webp)

## 미리보기 조작판
왼쪽(휴대폰에선 위쪽) 조작판에서 서버 판정 날짜를 바꾸고, 이웃/주인 화면으로 바로 이동할 수 있습니다.
실제 서비스 화면에는 들어가지 않는 개발용 도구입니다.
